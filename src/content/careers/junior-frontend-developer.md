### Job Description

We are seeking a Junior Frontend Developer to join our engineering team. The ideal candidate will have a solid foundation in HTML, CSS, and JavaScript and be keen to grow their skills building modern web interfaces. You will work alongside senior developers and designers on our website, which is built with Astro, React, TypeScript, and Tailwind CSS and hosted on Vercel, learning our codebase and contributing to real features from day one.

### Responsibilities

- Build and maintain user interfaces with Astro and React, following designs and guidance from senior developers and designers
- Write clean, accessible HTML, CSS with Tailwind CSS, and TypeScript, following the patterns already used in the codebase
- Fix bugs and make small improvements across pages and components, with feedback through code review
- Help keep pages responsive and easy to use across mobile, tablet, and desktop screens
- Collaborate with designers and other developers to turn designs into working pages accurately
- Learn how the site is built and deployed on Vercel, and ask questions when something is unclear
- Stay curious about frontend tools and techniques and share what you learn with the team

### Qualifications

- Bachelor's degree in Computer Science, Software Engineering, or a related field, or equivalent practical experience
- A solid foundation in HTML, CSS, and JavaScript, with some familiarity with TypeScript and React
- Familiarity with Astro and Tailwind CSS, or a willingness to learn them on the job
- Understanding of responsive design and how pages should behave on different screen sizes
- Personal projects, coursework, or a small portfolio demonstrating frontend work and problem-solving
- Willingness to learn, take feedback, and ask for help when needed
- Good communication skills and attention to detail
- Ability to work in a fast-paced, collaborative environment

### Benefits

- Competitive salary and performance-based bonuses
- Comprehensive health insurance package
- Flexible working hours and remote work options
- Professional development opportunities and support for further education
- Collaborative and inclusive work environment
- Access to modern development tools and technologies
